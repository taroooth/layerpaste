LayerPaste

Copy any web page into Figma as editable layers. One click, then ⌘V.
WebページをFigmaの編集可能なレイヤーとしてコピー。ワンクリック → ⌘V。

What it does / できること

  • Copy the visible area, a single element, or the full page / 表示中の画面・選んだ要素・ページ全体をコピー
  • Text stays editable text; boxes keep fills, borders, radius and shadows / テキストは編集可能なまま、図形は塗り・枠線・角丸・影つき
  • Gradients, inline SVG icons, images, canvas and video frames / グラデーション・SVGアイコン・画像・canvas・動画のフレーム
  • Layers named after the HTML / HTMLに沿ったレイヤー名
Free: 3 copies per day / 1日3回まで
